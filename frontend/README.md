# Aarogya frontend

Next.js 15 App Router UI for Aarogya (marketing, auth BFF, family/doctor/lab/admin shells).

## Run

```bash
cp .env.example .env.local
npm install
npm run dev
```

Requires the API at `API_INTERNAL_URL` (default `http://localhost:8000`).

Product styling tokens live in `app/globals.css` (Soft Structuralism for marketing).
